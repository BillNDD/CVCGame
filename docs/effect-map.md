# Effect map — what every test protects, and what it does not prove

GENERATED by `tools/effect-map.mjs`. Do not edit by hand: run the tool.
Gate G20 fails when this file and the test tree disagree, so a test with no row,
or a row for a test that no longer exists, blocks the build.

Per-test rows carry the test's own sentence, which in this project IS the
Given/When/Then effect. The requirement, oracle, platform, mutant family, evidence
and known limits are declared per FILE, in the tool, where they stay true.

Totals: 395 it() SITES across 22 files, plus 21 gates that are not test files.

A site inside a loop or a table runs many times, so Vitest executes MORE tests than these rows number. The rows count the places behaviour is asserted; the executed count is whatever the suite prints, and the gauntlet holds its floors.
